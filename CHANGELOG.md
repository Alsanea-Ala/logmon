# Changelog

All notable changes to this project are recorded here. Versions follow
[Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/); the
rules that map commits to versions are in [CONTRIBUTING.md](CONTRIBUTING.md).

The first release is `v0.1.0`. It covers the whole history up to the point
automated versioning was added, so it is a single large entry rather than an
incremental list.
